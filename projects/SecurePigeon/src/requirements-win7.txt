# Windows 7 兼容构建的依赖钉版（在 Python 3.8.10 环境中安装）
#
# 版本线依据：
# - Python 3.8.10  : 最后一个官方支持 Windows 7 的 CPython 版本
# - PyInstaller 4.10: 最后一个对 Win7 良好支持的 PyInstaller 大版本
#                     （5.x 官方声明 "Win7 应该也能用但不支持"，6.x 起要求 Win8+）
# - cryptography 42.0.7: 官方 changelog 明确 "Restored Windows 7 compatibility
#                     for our pre-built wheels"，且声明下一个版本不再支持 Win7，
#                     因此必须钉死在 42.0.7（不能升级）
# - Pillow 10.4.0  : 支持 Python 3.8 的最后一个大版本（12.x 已放弃 py3.8）
# - qrcode 7.4.2   : 支持 Python 3.8 的版本（8.x 要求 Python 3.9+）
#
# 目标机（Windows 7）要求：Win7 SP1 + 已安装 VC++ 2015-2022 运行库
# （vcredist_x86/x64）与 Universal CRT（KB2999226，一般经 Windows Update 已装）。

pyinstaller==4.10
pyinstaller-hooks-contrib==2022.15
cryptography==42.0.7
pillow==10.4.0
qrcode==7.4.2
pywin32-ctypes>=0.2.0
pefile>=2022.5.30; sys_platform == "win32"
